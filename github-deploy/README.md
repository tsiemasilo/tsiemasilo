# Tsie Masilo - Portfolio Website

A modern, responsive developer portfolio website showcasing personal projects and professional services with an innovative design and smooth user experience.

## Features

- **Dark Theme**: Professional dark interface with bright green accents (#00ff88)
- **Interactive Animations**: Matrix-style falling code background and 3D effects
- **Contact Form**: Real email integration via Gmail SMTP
- **Project Showcase**: Business LeadFinder, NoShedding, and other projects
- **Mobile Responsive**: Optimized for all devices
- **Modern Tech Stack**: React, TypeScript, Tailwind CSS, Framer Motion

## Tech Stack

### Frontend
- **Framework**: React 18 with TypeScript
- **Styling**: Tailwind CSS with shadcn/ui components
- **Animations**: Framer Motion
- **Build Tool**: Vite
- **Icons**: Lucide React & React Icons

### Backend
- **Runtime**: Node.js with Express.js
- **Email**: Nodemailer with Gmail SMTP
- **Functions**: Netlify serverless functions

## Deployment

This project is configured for Netlify deployment with:
- Automatic builds from GitHub
- Serverless functions for email handling
- Environment variables for secure configuration

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`
4. Build for production: `npm run build`

## Environment Variables

For email functionality, set these in Netlify:
- `EMAIL_USER`: Your Gmail address
- `EMAIL_PASS`: Your Gmail app password
